Project Context:
This exploratory analysis was completed as a core project during the 3MTT Data Science track. The objective was to demonstrate proficiency in handling large-scale public health datasets and extracting meaningful trends under a specific project brief.

Technical Execution:

Data Wrangling: Cleaned and pre-processed the global COVID-19 dataset, specifically addressing missing values (NaN) and inconsistent vaccination records.

Analysis: Tracked infection and mortality trajectories across diverse regions including Argentina, Australia, and Canada.

Tools: Python (Pandas for manipulation, Matplotlib/Seaborn for visualization).
